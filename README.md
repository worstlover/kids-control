# نگهبان خانواده — کنترل گوشی بچه‌ها با امتیاز

## بخش‌ها
- `supabase/schema.sql` — دیتابیس (کارها، امتیاز، ویش‌لیست، قوانین برنامه‌ها، مصرف)
- `supabase/functions/` — device-sync (همگام‌سازی گوشی)، device-submit (نمره‌دهی عکس تکلیف و دیکته با Gemini)، dictation-create (خواندن صفحه‌ی کتاب)، dictation-audio (خواندن جمله‌ها با صدا)، fetch-price (قیمت و عکس از اینترنت)
- `web/index.html` — پنل والدین
- `android/` — اپ گوشی بچه‌ها (قفل، زمان، تکلیف، امتیاز)
- `.github/workflows/build-apk.yml` — ساخت APK روی GitHub

## راه‌اندازی
1. **Supabase**: پروژه بساز، `supabase/schema.sql` را در SQL Editor اجرا کن. در Authentication یک کاربر (ایمیل و رمز خودت) بساز.
2. **توابع (خودکار)**: Node نسخه‌ی ۱۸ به بالا لازم است. در Supabase ← Account ← Access Tokens یک توکن بساز (با `sbp_` شروع می‌شود) و `Reference ID` پروژه را از Project Settings بردار. بعد:
   ```
   node tools/deploy.mjs --token sbp_xxx --ref REF --gemini-key AIza... --schema
   ```
   این دستور دیتابیس را می‌سازد (`--schema` فقط بار اول)، کلید Gemini را به‌عنوان secret ثبت می‌کند و هر پنج تابع را با تنظیم درست Verify JWT دیپلوی می‌کند. بعد از تمام شدن کار، توکن را در Supabase حذف کن (دسترسی کامل به حساب تو دارد).
   - اگر ترجیح می‌دهی دستی بروی: فایل‌های مستقل در `supabase/single-file/` را در داشبورد (Edge Functions ← Via Editor) با همان نام فایل بساز، برای چهار تابع غیر از `fetch-price` گزینه‌ی Verify JWT را خاموش کن و `GEMINI_API_KEY` را در Secrets بگذار.
   - اگر کد را تغییر دادی: `python3 tools/bundle.py` فایل‌های مستقل را دوباره می‌سازد.
3. **پنل والدین**: در بالای `web/index.html` مقدار `SB_URL` و `SB_KEY` (کلید anon) را بگذار و فایل را روی GitHub Pages یا هر هاست دیگر بگذار. وارد شو، فرزندان و کارها را اضافه کن.
4. **APK**: ریپو را در GitHub بگذار. در Settings ← Secrets دو مقدار `SB_URL` و `SB_ANON_KEY` را بساز. در تب Actions اجرای «Build APK» که تمام شد، فایل `kids-guard-apk` را دانلود و روی گوشی نصب کن.
5. **اتصال گوشی**: در پنل ← تنظیمات ← «افزودن گوشی» کد بگیر. در اپ گوشی کد و یک رمز والدین (۴ تا ۸ رقم) وارد کن.
6. **فعال‌سازی محافظت** (از «والدین» داخل اپ): دسترسی‌پذیری ← نگهبان خانواده ← روشن؛ مدیر دستگاه ← فعال؛ تنظیم اپ به‌عنوان صفحه‌ی اصلی.
7. در پنل، تب «برنامه‌ها» برنامه‌های مجاز هر فرزند را تیک بزن.

## دیکته از روی کتاب
بچه از صفحه‌ی کتاب عکس می‌گیرد ← Gemini متن را به جمله‌های کوتاه تقسیم می‌کند ← (اگر تنظیمش را نگذاشته باشی) تو در تب «دیکته» متن را با کتاب مقایسه و اصلاح و تایید می‌کنی ← بچه جمله‌ها را یکی‌یکی با صدا می‌شنود و روی کاغذ می‌نویسد ← از نوشته‌اش عکس می‌گیرد و با متن اصلی نمره می‌شود.
- صدا: `gemini-3.8-flash-tts` با صدای Kore؛ با secretهای `GEMINI_TTS_MODEL` و `GEMINI_TTS_VOICE` قابل تغییر است.
- متن فارسی کتاب اِعراب ندارد و ممکن است تلفظ بعضی کلمه‌ها درست نباشد؛ برای همین تایید متن توسط والدین به‌صورت پیش‌فرض روشن است.
- محدودیت: هر دیکته فقط یک‌بار نمره می‌گیرد؛ در روز حداکثر ۲ دیکته‌ی نمره‌گرفته (قابل تنظیم) و ۵ عکس صفحه‌ی کتاب برای هر فرزند.
- تو هم می‌توانی دیکته را در پنل مستقیم بنویسی.

## قواعد قفل
برنامه‌ای که برای فرزند تیک نخورده باشد قفل است. تنظیمات گوشی و نصب‌کننده‌ها فقط با رمز والدین (۱۰ دقیقه) باز می‌شوند. برنامه‌های «آموزشی» در سقف روزانه حساب نمی‌شوند. اپ‌های سیستمی، شماره‌گیر و کیبورد همیشه آزادند.

## نکته‌ها
- دوربین هنگام عکس تکلیف ۳ دقیقه مجاز است.
- اگر هوش مصنوعی در دسترس نباشد، تکلیف برای تایید خودت می‌آید.
- جست‌وجوی قیمت ممکن است روی بعضی فروشگاه‌های ایرانی از سرور خارجی بلاک شود؛ در آن حالت قیمت را دستی بزن.
- تست‌ها در `tests/` هستند (نیاز به PostgreSQL، PostgREST و Deno).
